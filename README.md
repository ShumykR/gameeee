# Head Bash Arena

Оригінальна 2D фізична гра для двох гравців у жанрі «car sumo»: збий суперника так, щоб будь-яка частина твого авто торкнулася голови його водія. Голова, що торкнулася землі (наприклад, після перевороту), теж програє раунд.
Уся графіка — процедурний піксель-арт, згенерований кодом з палітр; усі звуки — синтез WebAudio. Жодних сторонніх ассетів.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # Vitest: логіка, унікальність здібностей, механіки арен, валідація авто/мап, бот
npm run build      # продакшн-збірка в dist/
npm run e2e        # Playwright-смоук (потрібна збірка): скріншоти 915×412 і 1280×720 + перевірка консолі
```

## Керування

| | Ліворуч | Праворуч |
|---|---|---|
| Гравець 1 | `A` | `D` |
| Гравець 2 | `←` | `→` |

Дія (здібність авто): `W` для гравця 1, `↑` для гравця 2. На телефоні — кнопка-зірка над стрілками, вона заповнюється в міру перезарядки. Авто без здібності кнопки не мають.

На телефоні — по дві великі кнопки в нижніх кутах (мультитач, двоє гравців на одному екрані). У повітрі ті самі кнопки обертають авто (сальто). `Esc` — пауза, `` ` `` — показ фізичних форм.

## Що всередині

- **Фізика** (`src/physics`, `src/cars/car.ts`) — Planck.js, фіксований крок 60 Гц з акумулятором та інтерполяцією рендеру; WheelJoint з пружинною підвіскою, мотором і прогресивними відбійниками; PD-асистент вілі, керування в повітрі, повільне самопідвівання; групи/маски колізій.
- **Авто** — 270 авто у 13 колекціях. 22 оригінальні описані вручну (`src/cars/defs.ts`); решта зібрані генератором (`src/cars/factory.ts`) з 29 каркасів (седан, вантажівка, мотоцикл, гусеничний, істота, сани, тарілка…) і навісних деталей (драбина, колоди, ківш, пилка, гармата, роги, хвіст…), а маса, мотор і підвіска виводяться з пресетів архетипу. Список колекцій — `src/cars/roster.ts`, метадані й пошук — `src/cars/catalog.ts`. Кожне авто має власний **скін** — впізнаваний малюнок поверх фізичного каркаса (сани з завитими полозами, пожежна з драбиною й мигалками, двоповерховий автобус…): каркас лишається фізикою, а скін лише малює. Шаблони кузовів — `src/cars/skins.ts`, набір деталей (вікна, двері, бампери, решітки, мигалки, драбини, ферми, гусениці…) — `src/cars/draw.ts`, скіни оригінальних авто — `src/cars/originals.ts`. Рендер спрайтів (`src/cars/sprite.ts`): контур зовні силуету, п'ятитонове затінення на кожен матеріал, рамки вікон, роздільність 18 px/м.
- **Гараж** (`src/ui/garage.ts`) — сітка всіх авто з пошуком, фільтром колекцій і типів, карткою характеристик; той самий екран відкривається при виборі авто перед матчем.
- **Арени** (`src/maps/defs.ts`, `src/maps/caves.ts`) — 26 арен з паралакс-фонами. Вісім із них — печери й ферми: замкнені гроти зі склепінням, по якому можна проїхати на швидкості (`cavern()`), острови всередині, ґратчасті мости над прірвою, сині підйомні промені, зелені пружні стіни, червоний лазер, що вмикається й вимикається, і пилка-маятник на ланцюгу. З решти 10 тематичних під колекції (цвинтар, зимове містечко, ферма прибульців, мотодром, вулкан, пляж, стадіон з м'ячем, свято ліхтарів, розлом, іграшковий трек): лава, шипи, пилки, обриви, падаючі блоки, рухомі платформи, трампліни, низька гравітація. Декорації малюються кодом (`src/maps/decor.ts`). Режими «випадкова арена щораунду» і «випадкові авто щораунду».
- **Правила** (`src/game`) — очко за дотик до голови суперника, одночасний дотик = нічия; матч до N очок. Slow-mo, тряска, ragdoll водія, частинки.
- **Здібності** (`src/cars/kit.ts` — одна таблиця на всі авто, механіки в `src/game/game.ts`) — **кожна здібність унікальна**: жодні два авто не мають однакової дії, пасивки чи вантажу (це перевіряє `tests/kit.test.ts`). 96 авто мають власну активну здібність, ще 8 — пасивку, а разом із вантажем і важками щось своє має 114 авто; решта — «чиста їзда».
  - *Активні* (кнопка): стрибки (бігфут, приземлення з ударною хвилею, бекфліп, олі, місячний, гідравліка, дибки, кидок на суперника), ривки з ефектом при влучанні (жало б'є струмом, роги підкидають, жук перевертає, бампер відштовхує, акула кидає за спину), удари (клешня, бутса, ківш через себе, хвіст назад), хвилі (рик, розряд, виття плутає керування, стазис, промінь НЛО, блискавка з неба), захист (щит, панцир, дзеркало відбиває снаряди, вага, невидимість, привид), переміщення (портал, обмін місцями, петля часу, крижана стіна), 30+ різних снарядів (бумеранг-кістка, самонавідна ракета, торпеда, рейкотрон, трос евакуатора, чорнило, окріп…) і пастки (шипи поліції, мастило, гарячий асфальт, бетон, що застигає, подарунок-пружина…).
  - *Пасивні*: амфібія пливе у воді, фургон морозива губить ріжки, що заморожують, аптечка рятує від першого удару, гусениці ратраку чіпляються за схили, шипи відкидають, гумовий м'яч відскакує, медуза б'є струмом, дрегстер лишає вогняний слід. Вантаж у кузові (колоди, труна катафалка, корова, кавуни, шини…) теж пасивка — і теж унікальний.
- **Живі арени** (`src/maps/arena.ts`) — фонові об'єкти справжні: портали Розлому телепортують (авто, снаряди, м'ячі), мертва петля Іграшкового треку проносить швидке авто по колу, промінь НЛО затягує вгору, у ворота стадіону можна забити гол (заряджає здібність), парасолі на пляжі пружинять, на дах воріт храму можна заїхати, а гарбузи, подарунки, сіно, корови, конуси, шини й кубики — штовхаються.
- **Раптова смерть** (`src/maps/sudden.ts`) — своя для кожної арени: лава, приплив, метеорити, стіни, що сходяться, хуртовина, бомбардування, привиди, дощ із м'ячів, злива кубиків, невагомість. Через 25 с усе одно підіймається лава.
- **Музика** (`src/audio/music.ts`) — чиптюн-секвенсор на WebAudio: трек меню, три бойові треки по черзі, окремий трек для раптової смерті. Вимикається в налаштуваннях.
- **Бот** (`src/ai/bot.ts`) — 3 рівні складності; режим «проти бота» в меню (`SHOW_BOT_MODE` у `src/ui/menu.ts`), бот також грає демо на фоні меню і турнір балансу.
- **PWA** — маніфест (landscape, fullscreen), service worker, іконки (генеруються `npx tsx scripts/icons.ts`).

## Інструменти розробника

- `?gallery=1` — галерея всіх авто з характеристиками
- `?map=sky&p1=mammoth&p2=comet&debug=1` — швидкий старт матчу
- `npx tsx scripts/tune.ts` — вимірювання керованості кожного авто
- `npx tsx scripts/carcheck.ts` — валідація й тести керованості всіх авто (`CAT=dino` — лише колекція)
- `npx tsx scripts/balance.ts` — турнір ботів «кожен з кожним» для балансу
- `node scripts/maps-shots.mjs` — скріншоти всіх арен
- `npx tsx scripts/carsheet.ts out.png [колекція|id,id] [масштаб]` — аркуш спрайтів авто без браузера
